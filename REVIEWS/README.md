# Review archive

These are historical reviews, reproduction notes, implementation briefs, and verification records. Their code references, commands, findings, and status describe the revision each record examined; they are not current setup instructions or a list of findings that are all still open.

- [FINAL.md](FINAL.md) consolidates the September 2026 findings and triage.
- [IMPLEMENTATION.md](IMPLEMENTATION.md) records the fixes, commits, and verification follow-ups.
- `fixes/` holds individual tickets; `implementation/briefs/` and `implementation/lanes/` preserve the work records.
- The model-specific review files preserve the original assessments, including claims later corrected or refuted.

For current behavior and remaining boundaries, read [Safety](../docs/safety.md), [Invariants](../docs/correctness/INVARIANTS.md), [Retained residuals](../docs/correctness/RETAINED.md), and [Peering](../docs/peering.md). For current commands and build paths, use [Commands](../docs/commands.md) and [Development](../docs/development.md).

Old records intentionally retain names such as `apps/macos`, `[advanced]`, `ignore_files`, and `two-way-paranoid`. Their replacements are documented in the current guides; changing the original record would misrepresent what was tested.
