# Lane 0c notes
- LOCAL-01: new src/fsutil.rs + `pub mod fsutil;` in lib.rs. No call sites changed.
- API: private_dir(&Path), private_file(&Path) -> File (read+write), private_tempdir() / private_tempdir_in(state_root) -> PrivateTempDir (path(), removed on drop), sweep_private_tmp(state_root, max_age) -> usize, TMP_MAX_AGE (1 day).
- Extra public helpers: random_hex(bytes) for LOCAL-02's temp suffixes; private_tmp_root(state_root) for LOCAL-04's tray files.
- private_tempdir_in also runs private_dir on the state root itself, so it creates the root at 0700 if it is missing and tightens it, with a warning, if it is loose. That matches LOCAL-02's intent.
- An existing dir is tightened to (mode & 0700). It is not forced to 0700, so a user's 0500 is left alone. A newly created dir is forced to exactly 0700.
- The root-only test was also run under sudo (outside the isolated wrapper) and passed. Mutation checks: turning off tightening, the symlink refusal or the owner check each fails a test.
