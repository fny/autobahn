# Lane 0d notes
- Added src/text.rs (shell_quote, shell_join, display_safe, cap_line) and `pub mod text;` in src/lib.rs. No call sites touched.
- shell_quote always quotes, even safe strings ("" -> ''), so every output is exactly one word.
- display_safe escapes: \n \r \t by name; other C0 and DEL as \xNN; C1 (U+0080..U+009F) as \u{NN}. It does NOT escape backslash, so a name that literally contains the text `\x1b` looks the same as an escaped ESC. That's fine for display, but the output can't be reversed. Bidi overrides (U+202E etc.) are not control chars and pass through unchanged, since the ticket didn't ask for them.
- cap_line: the … (3 bytes) counts toward max_bytes; if max_bytes < 3 it cuts without a marker.
- `cargo fmt` rewrites the baseline src/transport/mux.rs; I reverted that each time (it's lane 0a's).
