## Details

- **Where `create_endpoint` keeps state.** It should take its state area from `crate::paths`, which honours `AUTOBAHN_HOME`, not from `$HOME` directly. Add a test-only way to pass the state area explicitly, and use it in every mux test, each with its own tempdir.
- **Session ids in tests.** Replace `mux-test-{len}` and `"session-1"` with `crate::session::session_identifier(..)` over each test's own paths. T1-2's validation requires real 32-hex ids.
- **Global environment changes in tests.** Remove `std::env::set_var` and `remove_var` from tests: `install.rs` sets `HOME`, `tests/supervisor.rs` sets `AUTOBAHN_SSH`, `AUTOBAHN_AGENTS_DIR` and the attach-command variable. Use explicit parameters, builders, or `Command::env` on the child process. Where a process-global value truly can't be avoided, serialize those tests behind one static lock, and restore the value in a drop guard. Don't add production knobs purely for tests unless they are small and harmless.
- **For T1-2:** add `is_session_identifier` and `Initialize::validate`, call it first in `create_endpoint`, delete the legacy `remove_dir_all`, and make `ancestor_copy_path` return a `Result` that validates the id.

Done means the whole suite passes, except the known flaky standing-watch test, and no test depends on the process's real `HOME`.
